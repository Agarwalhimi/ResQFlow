# ResQFlow — Professional Emergency Route Planner

ResQFlow is a Flask and Leaflet based emergency route planning project.

The main purpose of this project is to help emergency vehicles such as ambulances, fire trucks and police vehicles find a suitable route between a starting location and destination.

The system compares different available routes using:

- Distance
- Estimated travel time
- Traffic level
- Traffic delay
- Traffic signal delay
- Emergency type
- Route score

The project also includes a C language Dijkstra algorithm module for the PBL demonstration.

# 2. Main Features

ResQFlow provides the following features:

### Map

- Interactive Leaflet map
- OpenStreetMap street view
- Satellite view
- Zoom in and zoom out
- Search places on the map
- Select locations directly from the map

### Route Planning

The user can enter:

- Starting location
- Destination

The system then finds available routes and compares them.

### Route Analysis

Each route is analyzed using:

- Distance
- Estimated travel time
- Traffic level
- Traffic delay
- Number of traffic signals
- Signal delay
- Overall route score

The best route is marked as the recommended route.

### Emergency Modes

The system supports:

- Normal
- Emergency
- VIP
- Disaster

Emergency routes are given different analysis factors depending on the emergency type.

### Traffic

Routes can show different traffic levels:

- FREE
- LOW
- MEDIUM
- HIGH

The traffic information displayed by ResQFlow is generated by the project's backend analysis model.

It is not a commercial live-traffic service.

### Traffic Signals

The application estimates traffic signal points along the route.

The user can turn signal visualization on or off.

### Current Location

The browser's location service can be used to automatically select the user's current location as the starting point.

### Route History

Signed-in users can save their route searches.

The application stores:

- Starting location
- Destination
- Mode
- Emergency type
- Number of routes
- Recommended route
- Date and time

### User Account

Users can:

- Create an account
- Sign in
- Sign out
- View their account information

Passwords are stored using password hashing.

### Settings

The application provides settings for:

- Routing mode
- Traffic visibility
- Signal visibility
- Search panel visibility

These settings are stored in the browser's local storage.

## Updated landing page and responsive workspace

The first page is now a ResQFlow-specific landing page that explains the route-planning workflow and leads into the existing dashboard using the **Plan a route** / **Open ResQFlow** buttons. The dashboard remains in the same Flask page so its route planner, map, history and settings workflows can be used without a second server route.

Signal markers are displayed for the currently selected route only. Selecting a different route replaces the markers with that route's estimated signal points; turning the signal layer off removes them. Signal positions and delays are estimates along route geometry, not verified live traffic-signal inventory or live signal phases.

The landing page includes desktop, tablet and mobile layouts and respects reduced-motion preferences.


## Run the project locally

1. Install Python 3.10 or newer.
2. Open this folder in VS Code.
3. Install the required packages:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the Flask app:

   ```bash
   python app.py
   ```

5. Open `http://127.0.0.1:5000` in your browser.

The responsive layout is written with regular HTML, CSS and JavaScript so it is easier to understand and modify for a college project. Traffic-signal positions and delay values shown by the prototype are estimates, not verified live signal data.
